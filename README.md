# e-plantShopping

## Paradise Nursery Shopping Application

This repository (`e-plantShopping`) contains the React front-end application for Paradise Nursery, an online plant shopping platform.

### Features
* **Landing Page:** Overview of Paradise Nursery with quick navigation to the product catalog.
* **Product Listing:** Categorized display of houseplants with images, names, descriptions, and prices.
* **Shopping Cart:** Interactive cart functionality allowing users to add plants, adjust item quantities, view dynamic subtotals, and calculate total costs.
